# ASCII Screensaver Animations

Community animation library for the [ASCII Screensaver](https://github.com/Evol-Luci/ascii_screensaver_plugin_omarchy) Omarchy plugin.

## Browsing animations

Install the ASCII Screensaver plugin and open its **Marketplace** tab to browse and install animations directly from inside Omarchy.

## Authoring an animation

See [CONTRIBUTING.md](CONTRIBUTING.md) for the full authoring and submission guide.

## Index

[`index.json`](index.json) is the machine-readable catalogue consumed by the plugin. It is auto-generated on every merge — do not edit it by hand.
